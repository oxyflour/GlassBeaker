# 实验总结

## 模型精度对比

| 模型 | 训练样本 | Best dB MAE | 备注 |
|------|---------|-------------|------|
| structured_pair_spectral_head | 5280 | 4.49 | 参数化特征，当前最优 |
| Transolver (staged) | 5280 | 5.39 | 点云几何编码，~75 顶点 |
| Transolver (no staged) | 5280 | 6.94 | 未用 db/coupling weight |
| Temporal + staged | 1600 | 6.18 | 时域信号 + 几何，3× 少样本 |
| Temporal (200 样本) | 160 | 8.58 | 严重过拟合 |

**结论：** 换了三种编码方式（参数化、点云、时域），dB MAE 始终卡在 4.5-6 区间，未突破 4 dB。瓶颈不在模型架构，在输入信息量——FDTD 内部跑 28 万体素，模型只看到 75 顶点 + 几个标量。

## 逆设计优化器

### 全链路

```
cut/nib 距离 → surrogate → S(f) → Z 矩阵 → 电路求解 → η
    ↑                                                    │
    └──────────── 梯度反传 ← MC Dropout 约束 ←───────────┘
```

### 关键实现

- `antenna_efficiency`: S→Z→负载网络求解→效率，对 lossless PEC 精确
- `efficiency_objective`: softmax feed + sigmoid 软终端插值，全可微
- `termination_probs` 用软插值替代硬判（ground/open），梯度流畅
- `optimizer_farfield.py`: 桥接 chinatsu MNA 电路求解器，支持 .ffs 远场积分

### FDTD 验证

```
优化器预测: η = 50.5%
FDTD 实测:  η = 0.6%   (S11 ≈ 0 dB，全反射)
```

surrogate 被优化器 exploit 了——模型在分布外幻觉，预测和实测差 50pp。

### MC Dropout 不确定性约束

| 配置 | 最终 η | 不确定性趋势 |
|------|--------|------------|
| NoMC | 50.4% | N/A |
| MC(8×0.5) | 50.3% | 0.082→0.074 ↓ |
| MC(16×2.0) | 47.0% | 0.317→0.275 ↓ |

MC 能**检测**分布外（unc 飙升），但不能**修复**幻觉。甜点参数: n=8, weight=0.5。

## 时域信号预测

FDTD 前 500 步时域探针信号 → 1D ConvNet 编码 → 结合几何 → S(f)。

- 1600 样本达到 6.18 dB，证明时域信号含有效物理信息
- 3.3× 少样本下差距仅 0.8 dB，数据量补齐后有潜力
- 2000 样本数据集已生成 (`antenna-dataset-v3-td-200`)，含 9×10000 步时域探针

## 面采样

从 OBJ 三角面均匀采样替代顶点随机采样：
- 重复率 40%→0%（128 点全部唯一）
- 权重偏向端口和边缘区域
- 对 Transolver 50-epoch 结果无显著改善（6.94 vs 6.95 dB），因为顶点本身就太少

## 核心瓶颈

所有改进都指向同一个根因：**输入信息瓶颈**。

FDTD 计算在 56×80×64 hex mesh（28 万体素）上，模型只看到 ~75 个 OBJ 顶点。信息压缩比 ~3700:1。无论改编码方式、加时域信号、还是调 loss，都无法弥补这个差距。

## 建议方向

1. **将 FDTD hex mesh 暴露给模型** — nijika 已输出 `grid.json`，直接在体素网格上学 S 参数。这是信息量最大的 single change
2. **对抗闭环** — 优化→FDTD 验证→加入训练集→重训，迭代提升 surrogate 在关键区域的精度
3. **预训练+微调** — 大频域数据集预训练几何编码器，小批量时域数据微调
